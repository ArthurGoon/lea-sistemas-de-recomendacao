\section{Conclusão}
Neste protocolo, SVD é mais adequado para prever notas; KNN por soma, para
listas de dez. Este supera a popularidade nas cinco partições, mas não para
todos os usuários.

Os resultados se limitam às avaliações observadas, em dados antigos e sem
divisão temporal. Ausência de nota não implica desinteresse; as diferenças
entre partições com treinos sobrepostos são descritivas.
